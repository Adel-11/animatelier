# Sources des drapeaux (qff-flags-1)

Drapeaux SVG du dépôt GitHub hampusborgos/country-flags (fichiers issus de Wikimedia Commons, drapeaux nationaux dans le domaine public),
convertis en PNG 1200 px de large avec resvg. Aucune retouche.

Quiz : jp, ca, br, us, gb, de, mx, in, ch, ar, nz, pt, za, ie, jm.
Couverture (hors réponses) : fr, es, gr.
